## 规则（用户已确认）

- 每天最多推一只，没有符合标准的就不推，不推不计入分母；但交易日没推也要发一条简短通知。
- 新推的股只推 50 元以下的；三只做 T 底仓股（宁德时代、比亚迪、中芯国际）不受此限。
- 表统一九列：推送时间、参考价、参考买入价、现价、目标价、预计涨幅、两周截止日、四周截止日、状态。
- 目标价预期两周内达到，同时记四周截止日；两周内盘中触及算命中。
- 做 T 胜负：一次完成 = 同一只股同一天买入价和卖出价都触发；只触发一边不计；胜 = 扣除费用（卖出印花税 0.05%、佣金、过户费，合计约 0.112%）后仍赚钱。
